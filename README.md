# АРМ-112 — учебный тренажёр (MVP)

Рабочий Docker-MVP по приложенным материалам: роли обучающийся/преподаватель/администратор, учебные сценарии, имитация входящего вызова, карточка происшествия, тайминг, автоматическая первичная оценка, отчёты и аудит. Отдельными профилями предусмотрены локальный SIP (Asterisk) и локальный AI runtime (Ollama).

## Быстрый запуск

```bash
cp .env.example .env
# обязательно поменять SECRET_KEY и пароли
docker compose up -d --build
```

Открыть `http://SERVER_IP:8000`. Демо-учётки задаются в `.env`; значения по умолчанию: `student/student12345`, `teacher/teacher12345`, `admin/admin12345`.

Проверка: `curl http://127.0.0.1:8000/health`.

## Что работает

- Интерфейс по памятке: три телефона, адрес, ЕКП, признаки, оповещение и сохранённая карточка.
- 1 283 типа классификатора / 24 группы с условными правилами служб.
- 96 задач с оригиналами, импорт в сценарии и утверждение преподавателем.
- Режимы 112/ДДС, назначение занятий группе, мониторинг и остановка.
- Черновики, восстановление, статусы служб и рабочие звонки.
- Первичная/экспертная оценка, отчёты/CSV, аудит, управление пользователями.

[Разбор источников](docs/SOURCE_REVIEW.md), [интерфейс](docs/UI.md), [проверки](docs/VALIDATION.md).

## Остаток по ТЗ

SIP/WebRTC и голос, ML-оценка/генерация, адресные полигоны, полный архивный поиск, TLS, корпоративные учётные записи, хранение аудита >= 6 месяцев, автоматический внешний backup, мониторинг/HA и нагрузочные/аварийные испытания. OCR и эталоны проверяет преподаватель. [Матрица](docs/TRACEABILITY.md).

## Профили

```bash
# SIP
 docker compose --profile voip up -d

# локальный AI runtime (модель необходимо заранее загрузить/импортировать в изолированный контур)
 docker compose --profile ai up -d
```

В полностью изолированном контуре заранее привезите Docker images и AI model files. `ollama/ollama:latest` в production следует заменить на зафиксированную протестированную версию/внутренний registry.
