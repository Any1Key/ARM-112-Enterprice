# Эталонные голосовые ответы служб

Каталог содержит поставляемые учебные WAV-файлы для локальных SIP-звонков в службы 101–104 и дополнительные учебные номера. Для каждого варианта используются парные файлы `start` и `end`, поэтому начало и завершение разговора выбираются согласованно.

При запуске Docker Compose сервис `media-seed` копирует эти файлы в общий том `call_media`. Пользовательские записи разговоров и аудиовложения карточек сюда не входят и сохраняются только в Docker-томе и резервных копиях.
