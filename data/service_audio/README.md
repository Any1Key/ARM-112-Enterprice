# Эталонные голосовые ответы служб

Поставляемый пакет находится в `../service_audio.tar.gz`, а его SHA-256 — в `../service_audio.tar.gz.sha256`. Архив содержит 1220 WAV-файлов для локальных SIP-звонков в службы 101–104 и дополнительные учебные номера. Для каждого варианта используются парные файлы `start` и `end`, поэтому начало и завершение разговора выбираются согласованно.

При запуске Docker Compose одноразовый сервис `media-seed` распаковывает архив в общий том `call_media`, не перезаписывая уже существующие файлы. Пользовательские записи разговоров и аудиовложения карточек сюда не входят и сохраняются только в Docker-томе и резервных копиях.
