# Безопасность

MVP содержит JWT/RBAC и audit trail, но не является готовой защищённой конфигурацией. Перед вводом: заменить все секреты; включить HTTPS/TLS; не публиковать PostgreSQL/Redis наружу; настроить локальную IAM/LDAP по требованиям заказчика; определить MFA; ограничить SIP/RTP ACL; настроить ротацию/архив аудита минимум на требуемый срок; выполнить dependency/image scan; определить порядок обезличивания учебных данных и доступа к ним.
