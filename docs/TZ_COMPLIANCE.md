## Приёмочные проверки

Минимальный набор команд:

```bash
docker compose ps
curl -f http://127.0.0.1:8001/health
docker compose exec -T backup sh /verify.sh
node --check app/static/phone.js
git diff --check
```

Ручной сценарий входящего звонка: подключить браузер по `https://arm112.local:8443`, создать звонок преподавателем, убедиться в непрозрачном блокирующем окне, принять вызов, проверить открытие карточки и наличие события/записи в отчёте.

## Что требуется от заказчика для полного закрытия частичных пунктов

1. Машиночитаемые правила территориальной маршрутизации и подтверждённый справочник служб.
2. Размеченный набор ответов для калибровки ML-оценки.
3. Требования к корпоративной IAM/MFA, PKI, срокам хранения и обезличиванию.
4. Off-host backup, адреса мониторинга и канал оповещения.
5. Целевая нагрузочная площадка: 100 независимых браузеров, 20 SIP-телефонов и измерение RTP-задержки.
6. Формат презентации и официальные ссылки для сдачи на платформу.
