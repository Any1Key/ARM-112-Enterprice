# Проверка карточек в Chromium

Используйте отдельный Compose-проект с новой учебной базой и стандартными демо-пользователями. Проверка сохраняет и пропускает карточки, отправляет учебное SMS; рабочая база для неё не подходит. На свежей базе идентификатор студента — 3.

```bash
cd tests/browser
npm ci
npx playwright install chromium
BASE_URL=http://localhost:8000 node card-workflows.cjs
```

Проверяются все 24 группы опросных карт, АОН, числовые и множественные ответы, остановка времени регистрации, дополнение, возврат после пропуска, пустое обращение, очередь SMS и мобильный экран. Скриншоты сохраняются в `docs/screenshots`.

## Локальная телефония и нагрузка

В отдельном локальном Compose-проекте на `localhost:8000` включить профили `voip` и `ai`, затем:

```bash
node sip-proof.cjs
```

Нужен Python 3 для UDP-клиента. Прогон создаёт временные аккаунты с префиксом `sip_proof_`, принимает 20 вызовов в независимых сессиях Chromium, проверяет RTP, микрофон одной сессии, удержание, исходящий 101 и 100 параллельных запросов каталога. Остальные 19 сессий принимают аудио без захвата микрофона. Проверяются аппаратные REGISTER/401/Digest/200. Временные пользователи и попытки удаляются; результат без паролей сохраняется в системную временную папку. Для короткого прогона: `CALLS=1 node sip-proof.cjs`. Переопределение демо-паролей: `ADMIN_PASSWORD` и `STUDENT_PASSWORD`.

Прогон очищает оставшиеся аккаунты своего тестового префикса; запускайте его только в выделенном стенде.
